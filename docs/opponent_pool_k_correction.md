## 4) ⚠️ 更要紧的一条：**+0.09/轮 本身可能是被高估的**

```
它来自「+1.89 / 20 轮」✗ 而 +1.89 是在**无池**（纯自对弈）条件下量的 ✓
有池之后每轮增益：
  · **应该更大** ✓（对手有信息量 -> 学得更快 ✓）
  · **也可能更小** ✗（对手更强 -> 更难赢 -> 每轮提升空间小 ✓）
-> **方向未知** ✗ -> K 无法先验确定 ✓
```
**所以我的最终建议是「两段式」** ✗：
```
① 先用 **K=40** 跑**一代** ✓（裕度 1.89× ✓ 不必先知道每轮增益 ✓）
② 用这一代**实测的每轮增益**重算 K ✓
   · 若实测增益 > 0.0945 -> K 可以调小 ✓（跑得更快 ✓）
   · 若实测增益 < 0.0945 -> K 必须调大 ✗（否则检不出 ✓）
③ 而且**第一代就要同时量**「每轮增益」和「对 HOLDOUT 的最终增益」✓
   —— 两者的差就是**过拟合池子的量** ✓ 那正是这套设计要测的东西 ✓
```
**-> 把「K」当成一个**要用数据校准的参数** ✓ 而不是一次算定 ✓**
（这与今天学到的通则二一致：**最优值在平台期之前** ✓ 而平台期要靠数据找 ✓）
