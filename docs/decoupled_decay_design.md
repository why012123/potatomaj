# 解耦权重衰减：修法设计（待 mac 批 · 未动实现）

> server · 2026-10-16 · 状态：**只出设计** ✓ `net.py` 一行未动 ✓

---

## 0) 一句话

把 l2 从「**加在梯度上**」改成「**单独施加**」✗
-> 让收缩**成比例** ✓ 不再把权重恒定位移推死 ✓

---

## 1) 为什么（**证据链，全部有实测** ✓）

```
现状（`net.py:395`）：`grads[f"W{i}"] = acts[i].T @ g + **self.l2 * self.W[i]**`
  -> l2 是**梯度项** ✓ 而 Adam 会**归一化**梯度 ✓
  -> 当数据梯度趋零时，唯一梯度是 `l2*W` ✓
     `m/√v ≈ sign(W) = ±1` -> **每步位移 ≈ 恒定的 `lr`** ✗（不随 |W| 变小而变小 ✓）
  -> 权重逐步穿过所有量级，约 **1,400 步**撞 float32 的 denormal 地板 ✓
  -> **在地板堆积成「死权重」** ✓

实测（单变量对照 ✓ 同起点同数据同步数 ✓ 只改 l2）：
  3,000 步：l2=0 -> denormal **0**（最小权重纹丝不动 ✓）
            l2=1e-4 -> denormal **7,204**
两轮 BC：  l2=0 -> 死权重 43.1% -> **43.1%**（不动 ✓）
           l2=1e-4 -> 死权重 43.1% -> **80.0%**

性能（三轮独立 ✓ 每轮只改 l2 ✓）：
  +2.460（裕度 1.25×）/ +15.226（7.5×）/ +7.494（4.0×）✓ 均 p ≤ 0.001 ✓
  **保守下界 +2.46 ✓ 中位约 +7.5 ✓**
```

---

## 2) 改法（**最小改动 + 默认不变** ✓）

```python
# 现状（经典 L2：加在梯度上）
grads[f"W{i}"] = acts[i].T @ g + self.l2 * self.W[i]

# 改成：梯度里**去掉** l2 项
grads[f"W{i}"] = acts[i].T @ g

# 然后在 `_apply` 里**单独**施加衰减：
p -= lr * mh / (np.sqrt(vh) + eps)     # 只走数据梯度（Adam）
p -= lr * l2 * p                       # 衰减单独、成比例 ✓
```

**⚠️ 三条实现纪律** ✗（都来自今天踩过的坑 ✓）：
```
① **默认必须不变** ✗ -> 用开关控制 ✓ 例如 `Net(..., decoupled_decay=False)` 默认 False
   理由：改了它**所有已有模型不可比** ✓ 不能让默认值悄悄改行为 ✓
   （这正是「静默改变行为」那一类 ✓ 我们今天已经因为 `kl_n` 的静默默认值吃过一次 ✓）

② **`_apply` 是热路径** ✓ 上一轮我在这里做过 1.80× 的优化 ✓
   -> 新加的那一行要用 `out=` 复用缓冲 ✓ 别引入新的分配 ✓
   （我先前在 `_apply` 里踩过「每步 280 次白分配」✗ 别再犯 ✓）

③ **数值等价性**：开关为 False 时，必须与旧实现**逐位一致** ✓
   -> 用现成的安全网：`tools/equiv_before_after.py`（同机逐位 ✓）
   -> **这是必须的** ✗ 因为「加了开关但悄悄改了默认路径」是很容易犯的错 ✓
```

## 3) 我建议**不**改 `net.py` 的默认值（**这是本设计最重要的一条** ✗）

```
理由 ✗：
· 我们有一批已发布的模型 + 一批基于它们的结论（含三杠杆排序 ✓ 天梯 ✓）
· 默认值一改 -> 那些模型与新模型**不可比** ✓ 而结论的可追溯性会被破坏 ✓
· 而**开关**让两件事分开** ✗：
    现有训练流程 -> 不受影响 ✓
    新实验 -> 显式打开 ✓ 并在日志里留下「用了哪个模式」✓
-> 即：**默认零风险 ✓ 收益显式可选 ✓**
```

## 4) 验收（**四条，顺序不能反** ✗）

```
① **开关关着时逐位一致** ✓（`equiv_before_after.py` ✓ 同机 ✓）
   -> 证明「我没悄悄改默认路径」✓ **这条必须最先做** ✗
② 开关打开后：denormal 不再产生 ✓
   -> 判据：同起点、同数据、3,000 步 -> denormal **0**（对照 l2 现状的 7,204 ✓）
3) 开关打开后：死权重不变 ✓
   -> 判据：两轮 BC 后死权重 ≈ 起点值（对照现状的 43%->80% ✓）
```

## 5) 风险（**我如实列，不缩小** ✗）

```
① **它改变训练动力学** ✓
   解耦衰减的**有效强度**与经典 L2 **不等价** ✓
   -> 同样的 `l2=1e-4`，两种实现的**实际正则强度不同** ✓
   -> **不能假设「打开开关 = 修好了」** ✗ 它是**换了正则的定义** ✓
   -> 所以验收里除了「denormal 不再产生」✓ 还必须**再跑一次 A/B 确认性能** ✓
      （我在 §1 里那三轮用的是 `l2=0` ✓ 那是「完全不要正则」✓ **不是本设计** ✗）
```
**⚠️ 这一条很重要** ✗：
```
本设计**没有被直接验证过** ✓ 被验证的是「l2=0」✓
-> 解耦衰减**需要自己的一轮验证** ✓ 不能拿 l2=0 的结果替代 ✓
```

```
② 学习率 × 衰减的**耦合变了** ✓ 可能需要重调 `l2` ✓
③ 需要重训才能与已有模型比较 ✓（这是**决策成本**，不是技术风险 ✓）
```
