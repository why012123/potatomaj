### 四之二、夜里还跑了 RL（这条**没结论**，而且是「测不出来」而不是「变差了」✗）

server 在**干净引擎**上跑通了 20 轮 RL（从 `maj-pro4v1.1_mac_2ep` 起）：

```
✅ 链路跑通：20 轮全部完成，墙钟 7146s = **119 分钟**，8.21 核满载，**没有卡住**
✅ steps 338 -> 479
⚠️ 但**配对赛的测量没有分辨力** ✗：
   Δ = -3.764   SE = 3.197   单侧 p(A更好) = 0.880   双侧 p = 0.239
   σ=51.15 / 256 组   MDE = ±**8.96**
```

**为什么不能写「RL 让模型变差 3.8 分」** ✗：
```
门禁是 3.24 分 ✓ 而这次 MDE = 8.96 ✗ 是门禁的 **2.8 倍** ✗
-> 这个实验**没有能力分辨 3 分的差异** ✗
-> 正确结论是 **「不知道」** ✓ 不是「变差」✗
（Δ 点估计为负，但那只是信噪比太低的表现 ✓ 不是结论 ✓）
```
**已补跑（1500 组，只跑配对赛不重训）✓ 结果如下：**

```
Δ = **+0.325**   SE = ±1.169   σ=45.27 / 1500 组
单侧 p(A 更好) = 0.390    **MDE = ±2.91 < 门禁 3.24**  -> 这次有分辨力 ✓
```

**最终结论：20 轮 RL 在 ±2.91 的分辨率下，没有可检出的提升** ✓
```
既不是「变差」✗ 也不是「有用」✗  —— 就是**没差别** ✓
预注册门禁：① Δ > 2×SE = 2.34 ✗（0.325 远不够）② Δ ≥ 3 ✗  -> 未通过 ✓
```

**而这次补跑本身就是一条方法论证据** ✗ —— 同一个比较、同样的两个模型：
```
256 组：Δ = **-3.764**（SE 3.197，MDE 8.96）✗
1500 组：Δ = **+0.325**（SE 1.169，MDE 2.91）✓
-> **同一个比较能给出 -3.76 和 +0.33** ✗
-> 这就是「测量没有分辨力时，点估计就是噪声」的**直接实证** ✓
-> 也是我今晚第三次遇到同一类事（前两次：单 seed 的 ±4 分、实验组 seed2 的早停 ✗）
```

⚠️ **两点必须记住** ✗
```

   但**两个臂用完全相同的流程** ✓ 所以「各取 4 个种子的均值」仍是公平比较 ✓ 不剔除 ✗
② 实测 SD = **2.361**，比我先前假定的 1.85 大 ✗
   -> 门禁要按实测：Δ > 2 × √((SD_对照² + SD_实验²)/2)
      两臂同方差时 ≈ 2 × 2.36 = **4.7 分** ✓（不是 4 分 ✗）
③ 对照组 vs `mac_rl` = **-4.644**：这是**步数差**（17k vs 49.8k）+ 没 RL 造成的 ✓
   **不能**据此说「新数据会让模型变弱」✗ 也不是我要的结论 ✓
   我要的是「实验组 − 对照组」这一个差 ✓
```
