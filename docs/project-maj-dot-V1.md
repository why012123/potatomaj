## 五、算力与存储预算（必须提前说，不然会撞墙 ✗）

```

  合计 < 30 GB ✓ 充裕 ✓

网络 ✗（唯一的硬约束）：
  天凤**单会话** 0.93 局/秒 ✓ -> 100 万局 = **约 12.5 天** ✗

```
