# 走过的弯路（归档，没删）

这些是开发过程中试过、后来被替换掉的东西。**留着是为了可查，不是给人用的** ——
真正要运行的是根目录的 `土豆麻将.command`。

| 这里的东西 | 原来是什么 | 为什么换掉 |
|---|---|---|
| `run.sh` + `potatomaj/gui.py` | PySide6 的悬浮窗界面 | 那个窗口压在 WebGL 上，每次更新内容系统都要重新合成一块区域 —— 表现就是**卡 + 闪**。改成把提示画在游戏页面里就没这个问题了 |
| `gui_*.png` | 上面那个界面的截图 | 同上 |
| `run-battle.sh` + `土豆麻将对战.command` | 「自己开一桌三麻」的对战台 | 后来决定直接连雀魂，自己实现一桌牌局成本和风险都更高 |
| `土豆麻将Java.command` | Java 版的入口 | 试了一下，Node 这条路更顺 |

如果哪天想回头看某个思路，东西都还在。想彻底清掉直接删这个目录就行，
不影响任何正在用的功能（`archive/` 不被任何代码引用）。
