# 评测协议

> **一句话**：项目原来的评测（300 场同局配对）**最小可检出效应是 14.7 段位分**，
> 连 +4 都测不出来 ✗ 下面这套协议把它降到 **+2（约 30 分钟）**。

本文所有数字都是**实测**的，脚本在 `aimodel/arena_test.py`。

---

## 一、为什么原评测不可信（三个独立的坑）

### 坑 1：同局配对是**负优化** ✗

| | 三麻 | 四麻 |
|---|---|---|
| 同局两座位的相关系数 r | **−0.501** | −0.364 |
| 配对 A−B 的 σ | **90.4** | 61.0 |
| 若两者独立应为 σ√2 | 73.9 | 52.1 |

三麻是零和博弈，实测 r = −0.501，**正好是理论值 −0.5** ⇒ `σ(A−B) = σ√3 = 90.5`
（实测 90.4，吻合到小数点后一位）。

**配对不是削方差，是把方差从 73.9 放大到 90.4** ✗

### 坑 2：分辨率不够，却拿来下结论

| 评测方式 | 场次 | 实测最小可检出效应（MDE） |
|---|---|---|
| `ab.py` 同局配对 | 300 | **14.7 段位分** |
| `quick_eval` | 150 | **13.7 段位分** |
| `arena_test.py` 同牌山重放 | 1200 | **3.13 段位分** |

### 坑 3：选择偏差（赢家诅咒）—— **这条最致命** ✗

同一份权重，只换 16 个不同的 150 场测试集：

```
均值 −4.49   σ 5.15   范围 [−11.8, +5.0]   跨度 16.7 分
```

**在同一份测试集上，从 16 个「强度完全相同」的候选里挑最高的那个，虚高 +9.46 段位分**
（理论值 +12.1）。

而 `train.py` 的检查点逻辑是「评测新高就保存」，`quick_eval` 用的是**固定 `seed=999`**
—— 选择与报告用的是同一份牌局，这正是教科书级的选择偏差 ✗

**对照 `maj-normalv1.1.log` 的 16 轮实际读数**：

```
−5.4 → −4.3新高 → −9.7 → −3.9新高 → −5.3 → −1.7新高 → −2.3 → −2.4
→ −6.9 → +0.1新高 → −2.0 → −6.6 → −5.5 → −9.1 → −13.3 → −10.2
```

在 −13.3 ~ +0.1 之间乱跳、毫无趋势，跨度 13.4 分 —— **与 150 场评测的 MDE = 13.7 完全吻合**。
也就是说这 16 轮的波动**全是评测噪声**，「最好」的那个只是**在这份测试集上运气最好**。

> ⚠️ **推论：报告里「RL 比纯克隆 +3.65 段位分、p=0.014」不可信。**
> 单是选择偏差就有 **+9.46**，是效应量的 **2.6 倍**。

（Stouffer 那一项反而是小问题：同种子下不同对比的 ρ̄ = +0.100，
修正后 z = 2.28（报告 2.45）、p ≈ 0.011（报告 0.014）—— **不足以推翻结论**，
真问题是选择偏差。）

## 二、改进手段（按实测效果排序）

| # | 手段 | 实测效果 |
|---|---|---|
| 1 | **同牌山重放**（duplicate） | σ 90.7 → **57**，省 **2.5 倍**样本 |
| 2 | **SPRT 序贯提前停** | 真值 +2 省 **50%**；+4 省 **76%**；真值 0 时 95% 正确判平 |
| 3 | **换指标** | 300 组下 MDE：段位分 8.76 → **放铳率 3.7pp** / 一位率 6.7pp |
| ✗ | ~~同局配对~~ | **负优化**，σ 放大 1.22 倍 → **应停用** |

**⚠️ duplicate 只省 2.5 倍，不是数量级** —— 因为**两个模型一旦打法不同，牌局立刻分岔**，
之后各走各的、运气重新独立。这是实测出来的硬限制。

**SPRT 实测**（σ=61，目标 δ=+2）：

| 真实情况 | 平均场次 | 固定方案 | 省 |
|---|---|---|---|
| 真有 +2 | 3638 | 7315 | **−50%** |
| 真有 +4 | 1767 | 7315 | **−76%** |
| 其实没提升 | 2603（95% 判 H0 ✓） | — | 不误报 |

**附加发现**：只打**单手牌**（不是整个东风战）单位算力效率高 **2.79 倍**
（Δ/σ=0.0434 / 96ms vs 0.0891 / 1126ms）。但测的是「千点收益」，
**测不出顺位策略** —— 只能当快筛 ✗

## 三、推荐协议

```bash
# 目标 +2 段位分（约 30 分钟，4 进程）
python -m aimodel.arena_test \
    --a aimodel/weights/maj-normalv1.2.npz \
    --b aimodel/weights/maj-normalv1.2_bcbase.npz \
    --target-delta 2 --jobs 4

# 先只估时间不真跑
python -m aimodel.arena_test --a X --b Y --target-delta 2 --plan-only
```

| 想确认什么 | 配置 | 场次 | 耗时 |
|---|---|---|---|
| 有没有大提升（+5） | duplicate + SPRT，δ=5 | ~1200 | **10 分钟** |
| 有没有 +2 级提升 | duplicate + SPRT，δ=2 | ~3600 | 30 分钟 |
| 发版前对比 | duplicate 固定样本 | 6000 | 50 分钟 |
| 有没有**退化**（回归门禁） | duplicate + 教师锚点 | 1000 | 9 分钟 |
| 日常迭代 | 单手牌快筛 + 一位率/放铳率 | 2000 | 4 分钟 |

### 两条必须遵守的流程纪律

1. **选择用的测试集 ≠ 报告用的测试集** ✗
   `quick_eval` 的 `seed=999` **只用来选检查点**；对外报告用 `REPORT_SEED = 31337`。
   **同一个测试集既选又报，再多样本也救不了**（测试集会被反复过拟合）。
2. **不要每轮 RL 都做完整评测** ✗
   最优设计也要 30~50 分钟。**只在里程碑做**（每 10 轮 / 每次改特征）。

## 四、兜底锚点

| 锚点 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 内置启发式教师 | 强度已知、零成本 | 太弱，模型已追平 ⇒ 饱和 | **只适合回归测试** |
| 固定旧版本模型 | 可复现 | 只能检出**大**退化 | 发版门禁 |
| 固定牌谱的决策一致率 | **零方差**、秒级 | 测的是「像不像教师」不是「强不强」 | 训练健全性检查 |
| 人类（雀豪/雀圣） | 唯一能答「打不打得过人」 | 每人需 **400+ 局**才有 0.056 的平均顺位分辨率 | 绝对强度校准 |
| 单手牌快筛 | 省 2.8 倍 | 测不出顺位策略 | 日常迭代 |

**推荐组合**：日常用「单手牌快筛 + 一致性检查」；发版前用「duplicate + SPRT(δ=2) + 教师回归门禁」；
季度用人类对战做绝对校准。

---

## 五、这套方案解决不了的

1. **无法便宜地检出 +2** —— 最优也要 30~50 分钟 ⇒ 不该每轮 RL 都做完整评测。
2. **选择偏差只能靠流程消除**，统计手段救不了。
3. **SPRT 需要 σ 先验** —— 真值未知时用 σ=57（三麻）/ 42（四麻）会略偏乐观；
   建议先跑 200 组估 σ 再启动。
4. **duplicate 消不掉「混沌分岔」的方差** —— 只省 2.5 倍。
5. **单手牌指标与段位分目标不一致** —— 只能当快筛，不能当结论。
6. **四麻没实测** —— 本次时间都花在三麻上；四麻 4 家分岔更长，协议要重测。
